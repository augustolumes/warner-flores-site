# Warner Flores — Catálogo mobile

Catálogo responsivo mobile-first para a Warner Flores, com navegação por Início, Catálogo, Buquês e Contato. As opções de decoração abrem uma tela de detalhes e o pedido de orçamento é preparado em um bottom sheet com encaminhamento para o WhatsApp.

## Arquivos

- `index.html` — páginas e componentes do catálogo
- `style.css` — identidade visual, layout responsivo e estados de interação
- `script.js` — navegação, filtros, opções de buquê, detalhes e orçamento via WhatsApp
- `imagens/` — fotos locais das opções de decoração

Abra `index.html` no navegador para visualizar o site. Para publicação, envie os arquivos e a pasta `imagens/` para o serviço de hospedagem escolhido.
